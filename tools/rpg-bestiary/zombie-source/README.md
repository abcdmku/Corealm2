# Source zombie family

`buildSourceZombie(id)` returns the three zombie candidates. It preserves Quaternius Universal Base Characters topology, UV texture maps and 65-joint skin weights. Existing peasant clothing supplies the tunic, trousers and boots. A coherent deformation changes vertices and bind joints together.

The base zombie has narrower cheeks and waist, an uneven shoulder, a slightly slack asymmetric face and muted skin stains. The plague zombie adds an enlarged abdomen and uneven shoulder swelling, plus a second tunic opening. The grave ghoul has shortened legs, elongated forearms and fingers, a bare gaunt torso, deeper crouch and eight tapered claws attached to actual finger joints. Clothing triangles are removed at torn openings; hidden body triangles are removed only beneath clothing, keeping visible skin in the openings. Removed vertices are compacted so they do not affect bounds.

The corpse revision in `corpse-textures.mjs` transforms the original albedo itself instead of multiplying warm skin by a tint. It keeps anatomical luminance and UV placement while painting pale gray-green, jaundiced and cold-gray variant palettes. Eye sockets and cheek masks use UV coordinates checked against actual source vertices. Eyes become cloudy, cheek wounds have dried dark centers and bruised rims, and clothing becomes faded burial fabric. Stronger cheek recession and arm narrowing reduce the healthy silhouette. Lip triangles are removed for a recessed dark mouth with six exposed teeth; the left sleeve tears open to reveal pallid shoulder skin. None of these appearance changes alter the source clip phases.

Idle, Walk and Attack use the actual UAL2 `Zombie_Idle_Loop`, `Zombie_Walk_Fwd_Loop` and `Zombie_Scratch` takes. Run uses UAL1 `Jog_Fwd_Loop`; Hit and Death use `Hit_Chest` and `Death01`. Directional hits add a limited spine recoil to the source hit. The ghoul retarget adds its deeper spine crouch. Contact phase is measured from maximum forward right-hand extension in the source scratch clip, and remains subject to production contact review.

`read-glb.mjs` is a CPU-only accessor reader. It rejects sparse and unsupported source accessors. Top-level texture extraction converts embedded or referenced images to PNGs under ignored `derived/`; the exporter receives original albedo, normal and packed metallic-roughness bindings without vertical flipping. Geometry grounding samples every source key and 120 Hz points against the whole skinned model and attached claws.

Inputs are the existing `game/public/assets/models/character/base_male.glb`, peasant outfit GLBs, `animation/animation_library_1.glb`, and the shared read-only extracted `tools/rpg-bestiary/humanoid-source/derived/UAL2_Standard.glb`.
