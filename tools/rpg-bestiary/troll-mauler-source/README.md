# Troll Mauler source adapter

Original complete unhorned Troll Mauler by **piacenti**, [creator page](https://opengameart.org/content/troll-mauler), CC-BY-3.0. Original SHA256: `83fc5e524d31020d8b7c9641517f965cecd65840b3119582b4e984649f708c51`.

`buildTrollMauler(id)` returns an async `{object, clips, meta}` with the original medium body, visible original loincloth, eyes, original 33-bone rig and native Idle. Original UVs and packed body/cloth/eye images are preserved. Legacy materials are reconstructed as rough nonmetallic materials; texture paths are provided through `meta.textureBindings` for the parent exporter. Occlusion paths remain unbound metadata: verified original slot 2 multiplies **diffuse color**, at 0.5 for med and 1.0 for cloth. This is not equivalent to standard ambient-occlusion shading, so do not rename these paths to `aoPath`. Exact source slot evidence is in `legacy-material-slots.json`; the layer is now composited in linear light into separate med-legacy-color.png and cloth-legacy-color.png runtime textures. Original images remain untouched; derived/legacy-color-recipe.json records the formula, source color conventions and all hashes. Run node tools/rpg-bestiary/troll-mauler-source/compose_legacy_color.mjs after source preparation. No body reshaping, grafts or replacement primitives were used. Low source body, duplicate cloth, source floor/cameras/lights are excluded.

Preparation uses the verified portable Blender 4.5.11 runtime with `--background --factory-startup --disable-autoexec --python tools/rpg-bestiary/troll-mauler-source/prepare.py`. It reads the pinned source from the scoped source cache and writes only this helper's derived directory and `test-results/troll-mauler-source`. It never saves the original blend. Run `node tools/rpg-bestiary/troll-mauler-source/check.mjs` for the CPU adapter check.

Four-influence reduction is normalized and fitted across 92 source and authored poses, choosing only existing source influences. `refit.py` ranks all four-influence subsets, runs exact nonnegative least squares on the best candidates, then minimizes worst-pose error for difficult vertices. It changes 470 vertices' weights; topology, positions, UVs and original joints remain unchanged. The source contains stale groups that are not armature bones; these are excluded from the fit.

Final independent Blender comparisons: Idle body 10.99 mm / cloth 31.56 mm / eyes zero; authored body at most 11.24 mm / cloth at most 66.88 mm / eyes zero. Overall authored RMS is at most 2.82 mm. The initial 315 mm worst error fell to 66.88 mm, concentrated in the original cloth. Earlier sub-millimeter Idle figures were invalid because legacy action-slot assignment had left that initial comparison under-evaluated. They are superseded by the explicit-slot results above. Source deformation is approximate, not exact.

The factory emits only the genuine Idle take and lists the five states the source lacks in `meta.missingNativeStates`. The studio UAL retarget that produced the current production Walk, Run, Attack, Hit and Death (`studio-troll.ts`) is retired; the troll needs a full rest-relative humanoid retarget (Blender) before its production file changes.

Run `node tools/rpg-bestiary/export-expansion.mjs troll_mauler --out test-results/troll-mauler-source/export` for the complete six-state candidate. Its floor correction is evaluated against final interpolated animation channels, then limited to a body-relative speed. Numerical checks do not approve the movement: every state still requires production devdocs review before promotion, including gait contacts, strike, cloth deformation, held corpse and recovery to Idle.

The motion repair preserves the body, cloth, eyes, geometry, textures and existing skin weights. Rebuilt archive materials retain the production cloth's alpha mask and 0.5 cutoff for its transparent ragged hem. Attribution must identify piacenti and CC-BY-3.0, link the source/license, and disclose material conversion, the existing weight refit and studio motion transfer.
