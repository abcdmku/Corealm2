# Gloamplate Reaver candidate

This is the high-tier Wilderness candidate built from starred Tripo card `af6d578f-d3c2-4bf0-8178-ac92a20b34d8` (source project `e1b8c030-b812-4b78-b4d7-4216e8a4a603`). The visual design and gameplay placement are still pending the root agent's browser review.

The exported GLB already contained one skinned mesh, a 67-joint humanoid rig, and an actual 2.33 second `walk` clip. That clip has 201 channels, but 178 samplers were marked `STEP`, which would make its motion snap between keys. The builder retains every source key and changes those samplers to `LINEAR`. It adds separate `Idle`, `Run`, `Attack`, `Hit`, and `Death` clips on the same joints. `Run` derives from the source gait, compressed to 1.82 seconds with a modest stride increase.

The mesh's 3,837 vertices, 4,878 triangles, positions, normals, UVs, indices, skin weights and inverse binds are retained. Existing base-color, normal, and metallic-roughness maps stay at 2K and are copied byte-for-byte. The Unity/Mixamo naming pass changes joint labels only. The root scale makes the source's 0.842 m height approximately 2.40 m while keeping the floor at y=0.

Rebuild and verify with:

```powershell
node assets/art/tripo/imports/creatures/new-star-dark-armored-demon/build-candidate.mjs
```

`catalog.json`, `lab-catalog.json`, and `verification.json` are generated by the builder. `accepted`, `rigAccepted`, `motionAccepted`, `texturesAccepted`, `labAccepted`, and `worldIntegrated` remain false until the root agent checks the model in the feature lab and reviews the art.
