# Original Starhide texture sources

This folder retains the first Starhide prototype's texture inputs and rendering scripts. Its superseded candidate GLBs, Blender assembly, ZIP and review renders were removed during cleanup.

The delivered T50 and T70 sets are documented in [the current armor package](../tier50-70/README.md). T90 is documented in [the Aurora package](../aurora/README.md).

Shared source under `tools/item-models/starhide/` remains part of the current armor builders, including native hand geometry and Blender import support. The original prototype can still be regenerated with its authoring scripts if needed.
