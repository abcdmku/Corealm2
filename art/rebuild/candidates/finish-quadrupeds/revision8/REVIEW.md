These frozen mammal bytes still contain the older animation sampling. Subsequent CPU diagnosis found actual rigid soles sagging between otherwise correct authored keys. The source now uses denser sampling, reducing all sampled full-mesh penetration below 1 mm; that source has not been re-exported here. See the parent `penetration-review.json` and preserved before report. Art improvements are not evidence of planted travel.

The complete-source search checked all 18 locally cached Unity archives and additional relevant model paths. No exact fox, Lynx, badger or porcupine was found. A complete open Fox source has now been acquired for a fair silhouette comparison; another Lynx candidate remains unacquired behind the official authenticated download API. No further small paw/coat revision is being treated as a substitute for that source decision.
