Extremely low-poly cat model I've quickly put together for testing purposes. Maybe you will find another use for it.

I made the texture from CC0 photos from Wikimedia Commons.

There is a very simple walk animation in the Blend (2.8) file consisting of two shape keys. EDIT: Added an extra texture (cat_free.png) that's been created solely by me, from scratch, so that you can be better sure about the CC0 status.
