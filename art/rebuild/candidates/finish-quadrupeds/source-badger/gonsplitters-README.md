### Usage

The minis will be accessible to the respective plugin that has been installed to load the asset in.

## Installing via R2ModMan
1. Open up r2modman, select talespire and the profile you want to install this on.
3. Navigate to Online, find this pack and click Download (Latest).
4. Make sure [CALP](https://talespire.thunderstore.io/package/PluginMasters/Custom_Assets_Library_Plugin/) is also installed.
