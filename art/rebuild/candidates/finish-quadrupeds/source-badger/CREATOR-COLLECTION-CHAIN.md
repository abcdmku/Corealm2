# Badger creator collection lead — unresolved exact grant

Checked 2026-09-05. This extends the provenance trail but does not clear the candidate's original creator license.

The creator post https://mz4250.com/posts/appendix-updates-58583354 links the public collection:

https://www.prusaprinters.org/prints/78063-misc-creatures-for-tabletop-gaming-collection-wip

The corresponding current Printables route is:

https://www.printables.com/model/78063-misc-creatures-for-tabletop-gaming-collection-wip

The collection is also indexed as Thingiverse 4982755:

https://www.thingiverse.com/thing:4982755

The Mini Index https://www.theminiindex.com/Minis/Details?id=35528 names the collection and mz4250, includes Badger among its species tags, and points to Thingiverse. The creator's Reddit announcement https://www.reddit.com/r/3dprintingdms/comments/rn229n also points to PrusaPrinters 78063. These support the collection's identity and creator association. They do not establish that the present Gonsplitters mesh is the same original Badger.stl, nor a license for that exact original.

Primary access results:

- Printables model page: direct read-only HTTP request returned 403. Web text retrieval returned an internal/unavailable error, including its shortened canonical ID route.
- Thingiverse model page: direct read-only HTTP request returned 429. Web text retrieval returned a page with no text.
- Printables anonymous metadata API: one query requesting the collection name, creator, license and STL filenames/sizes returned 403. No login, borrowed credentials, challenge solving, header spoofing or further retries were attempted.
- Search queries restricted to exact Printables/Thingiverse collection identifiers and license terms did not return a primary cached license declaration.

A secondary index reportedly lists Badger.stl and an Attribution license, but this remains a lead. The required next evidence is a primary collection/file license record, plus sufficient file or geometry identity to link its Badger to the Gonsplitters derivative. A license attached to another mz4250 model does not fill either gap.

Both preview catalogues continue to say publisher-declared CC-BY-SA4 with original creator grant unverified. No license flags, geometry or assets were changed during this research pass.
