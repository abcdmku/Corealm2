# Free tapir source search

No complete source was acquired. The [inventory](./inventory.json) distinguishes inaccessible leads from rejected licenses and paid models. No candidate has received visual approval, so there is no source hash or preview evidence to promote.

The most concrete free creator listing is [Tapir boar by dinosaurfan5678](https://www.cgtrader.com/free-3d-models/animal/mammal/tapir-b5245a10-917d-451d-83da-ea354797772d). It lists a 1.08 MB Blender file and a Royalty Free No AI license. A direct public request returned HTTP 202 with an empty response, recorded as `cgtrader-page.html`. The linked preview did not open through the web tool. Its quality, license details and source download remain unverified.

[Meshy's individual tapir listing](https://www.meshy.ai/3d-models/019c6c62-1c3e-782f-ba77-00828e25ff83) is search-indexed as CC0, but neither its preview nor model file was acquired. The [gallery](https://www.meshy.ai/tags/tapir) says accounts are required for downloads. Gallery claims about rigging, topology or texture quality were not treated as inspection evidence.

[Kenchoo's Megatapirus](https://sketchfab.com/3d-models/megatapirus-79cbf7a3f29a43aead9dd80ac284caae) is explicitly CC BY-NC-ND and rejected. Its description credits a supposedly CC BY original from SAVIA_Colombia, but that source was not independently retrievable. The maker's attribution alone is insufficient to acquire the restricted remix as a substitute.

The University of Pisa's freely downloadable scan is a skeleton. CadNav's exterior model and Vortex Ally's cartoon figurine are noncommercial. The remaining store models are paid. No rips, gated endpoint workarounds, purchases or public changes were made.

This is a bounded unsuccessful acquisition search, not proof that no suitable free model exists. Revisit only with an accessible creator download and its original license, then inspect the whole body before rigging or replacement work.
