# Bedded shortcut prototypes

Closed ring surface carrying barycentrically sampled scan depth and UVs. The source face mirrors continuously across the rear. Authored taper and rearward crown form a grounded complete mass. Normals recomputed after deformation; embedded original maps retained. This is a sculptural derivative, not unchanged source geometry.

Source: Dario Barresi / Poly Haven, Rock Face 01, CC0-1.0. Source files, hashes and license evidence are recorded in the linked provenance file. Original embedded maps are retained. No public assets or world placements are changed.
